# Operator handbook

Five chapters, ~30 minutes each. Read in order the first time.

| # | Chapter | Goal |
|---|---|---|
| [1](01-what-this-is.md) | **What this is** | Honest description of capabilities + limits in 5 minutes |
| [2](02-setup.md) | **Setup** | Hardware, install, calibration, 5-friend test workshop |
| [3](03-run-a-workshop.md) | **Run a workshop** | Pre-event checklist, scripted briefing, operator's keyboard rhythm, post-event debrief |
| [4](04-when-it-breaks.md) | **When it breaks** | The five most-common failure modes + how to recover |
| [5](05-whats-coming.md) | **What's coming** | 2028 destination, 90-day plan, how to contribute |

A new operator graduates when they've ticked every *"you've done this if…"* checklist across the five chapters.

The handbook itself is per [ADR 0060](../adr/0060-operator-handbook.md).
Implements the path from *"developers can use it"* to *"facilitators can use it."*
